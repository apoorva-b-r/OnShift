# OnShift Backend Service

Node.js, Express, TypeScript, and Mongoose ODM REST API gateway for OnShift.

## Responsibilities
- Worker identity registration
- Evidence metadata persistence
- Orchestrating reconciliation and verification calls
- Cryptographic credential issuance (Ed25519)
- Government scheme catalog & matching endpoints

## Commands
```bash
npm run dev      # Start dev server on port 4000
npm run build    # Compile TypeScript
npm run test     # Execute Jest tests
```
