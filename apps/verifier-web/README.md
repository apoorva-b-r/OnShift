# OnShift Verifier Web Portal

React + Vite + TypeScript web application for external verifiers (banks, landlords, scheme admins) to validate Ed25519 signed credentials and view worker-disclosed claims.

## Features
- Client-side Ed25519 signature verification
- Issuer authenticity verification
- Display of selectively disclosed claims without leaking undisclosed transactions

## Commands
```bash
npm run dev      # Start Vite dev server on port 3000
npm run build    # Build static distribution
```
