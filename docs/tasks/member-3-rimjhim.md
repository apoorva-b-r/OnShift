# P0 Tasks
1. **Express Server Setup**: Express API router namespace on `/api/v1/`.
2. **MongoDB Connection**: Connect to MongoDB via Mongoose using `MONGODB_URI` with clean fallback handling when offline.
3. **Core Endpoints Implementation**:
   - `GET /health` (Returns HTTP 200 OK).
   - `GET /workers/:id`, `POST /workers`.
   - `GET /evidence/worker/:workerId`, `POST /evidence`.
   - `POST /reconciliation/run` (Proxies request to Python Verification Engine).
   - `POST /verification/level` (Proxies request to Python Verification Engine).
   - `POST /credentials/issue` (Calls credential signing service).
   - `POST /credentials/verify` (Calls signature verification service).
   - `GET /schemes`, `POST /schemes/match`.
   - `POST /consent/request`, `GET /consent/status/:consentId`.
4. **Jest Integration Tests**: Ensure test suite passes cleanly (`npm --prefix apps/backend test`).
